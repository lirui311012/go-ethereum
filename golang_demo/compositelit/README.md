# 复合字面量

复合字面量用花括号一次性写出一个值。结构体、数组、切片、map 都能这样写。起点是这一行：

```go
a := Account{Address: Address{19: 1}, Balance: 5, Nonce: 1}
```

外层是结构体：按字段名填 `Address`、`Balance`、`Nonce`。内层是数组：按下标填，`19: 1` 只改第 20 个字节，前面 19 个字节保持 0。合在一起就是地址 `0x00…01`、余额 5、nonce 1。测试里常用这种写法造一个最小账户。

`Address` 是 `[20]byte`，下标从 0 到 19。`Account` 有三个导出字段。

在本目录执行：

```sh
go run .
```

只用标准库。下面按程序的打印顺序说明，完整输出在文末。

## 1. 结构体按字段名写

字段名在冒号左边，值在右边。顺序可以和声明不一致，没写的字段是零值。

```go
a := Account{Address: Address{19: 1}, Balance: 5, Nonce: 1}
```

打印出来地址是 40 个十六进制字符，最后一位是 1，余额 5，nonce 1。字段名写出来之后，顺序可以和结构体声明不一致，两个值仍然相等。

## 2. 数组按下标写

`Address{19: 1}` 不是「19 个 1」，而是「下标 19 的元素是 1」。其余元素没写，仍是 0。

```go
full := Address{19: 1}           // 只有最后一字节是 1
sparse := Address{0: 0xaa, 19: 1} // 首尾各写一字节
positional := Address{1, 2, 3}   // 从下标 0 起按顺序填
```

`full[19]` 是 1，`full[0]` 是 0。`Address{1, 2, 3}` 填的是前三个字节，打印出来是 `010203` 后面一串 0。

下标必须是常量，范围落在数组长度里。同一个下标写两次会编译失败。

## 3. 切片和 map 里可以省略内层类型名

外层已经声明了元素类型或键类型时，内层花括号可以不再写类型名。结构体字段不行：字段的类型即使一眼能看出来，也必须写出来。

```go
// 编译不过：结构体字段缺类型
// Account{Address: {19: 1}, Balance: 5, Nonce: 1}

a := Account{Address: Address{19: 1}, Balance: 5, Nonce: 1}

accounts := []Account{
	{Address: Address{19: 1}, Balance: 5, Nonce: 1},
	{Address: Address{19: 2}, Balance: 8, Nonce: 0},
}

balances := map[Address]int{
	{19: 1}: 5,
	{19: 2}: 10,
}
```

`[]Account` 的元素省略了 `Account`。`map[Address]int` 的键省略了 `Address`。元素和键自己还是复合字面量，规则照旧：结构体按字段名，数组按下标。

## 4. 没写的字段是零值

`Account{Balance: 5}` 只填余额。`Address` 是 20 个 0，`Nonce` 是 0。`Account{}` 三个字段全是零值，和 `var a Account` 得到的值相同。

零值对每个类型都确定：整数 0、数组全 0、切片和 map 是 `nil`、字符串是 `""`、指针是 `nil`。

## 5. 切片也可以按下标写

切片字面量和数组一样，可以按位置写，也可以按下标写。长度由最大下标加 1 决定，容量等于长度。没写到的位置是 0。

```go
[]int{1, 2, 3}     // [1 2 3]，len=3
[]int{2: 9}        // [0 0 9]，len=3
[]int{1, 4: 5, 6}  // [1 0 0 0 5 6]，len=6
[4]int{1: 7, 3: 8} // [0 7 0 8]，长度写在类型上
```

`1, 4: 5, 6` 的意思是：下标 0 是 1，然后跳到下标 4 写成 5，接着按顺序把 6 写到下标 5。数组的长度在类型里已经定了，没写的位置补零，不能靠字面量把长度撑大。

## 6. map 必须按键写

map 没有「按位置」的写法，每一对都是 `键: 值`。键如果是复合类型，可以像第 3 节那样省略类型名。

```go
balances := map[Address]int{
	{19: 1}: 5,
	{19: 2}: 10,
}
```

用同样的字面量当查找键：`balances[Address{19: 1}]` 得到 5。键不存在时读到的是值类型的零值，这里是 0，和「余额真的是 0」打印出来一样。条目数仍是 2。要区分这两种情况用两返回值的读法：`v, ok := balances[k]`。

## 7. 取地址得到指针

`&Account{...}` 先造出结构体，再取地址，得到 `*Account`。不必先放到变量再取地址。

```go
p := &Account{Address: Address{19: 1}, Balance: 5, Nonce: 1}
p.Balance = 9
```

改的是这块新分配的结构体。切片元素类型是指针时，内层可以同时省略 `&` 和类型名：

```go
list := []*Account{
	{Balance: 1},
	{Balance: 2},
}
```

每个元素都是 `*Account`，不是 `Account`。

## 8. 按字段顺序写可以，少用

不写字段名时，必须按声明顺序写出每一个字段：

```go
positional := Account{Address{19: 1}, 5, 1}
keyed := Account{Address: Address{19: 1}, Balance: 5, Nonce: 1}
```

两个值相等。字段一增、一删、一调换顺序，按位置的字面量就会填错字段，编译器不一定报错。按字段名写不受声明顺序影响，缺了哪个字段也看得出来。本目录其余各节都按字段名写。
